What the code actually does

One code, two roles

There's no separate coach link and swimmer link. Whoever has the code signs up, picks Coach, Swimmer, or Parent, and enters it — same code either way.

Made the moment a team exists

Creating a team and getting a join code aren't two steps. A coach who chooses "Create a team" at sign-up becomes its manager and gets the code back in the same response.

Regenerate stops the old one cold

No grace period. The moment the manager regenerates, the previous code is dead — it just won't match anything anymore.

You can see who actually joined

The Team page's member list and the onboarding wizard's invite step both show real accounts as they join, each with their role, not just a static invite count.

Where you'll find it

Two places, same code.

Team page

The manager sees the code, a Regenerate button, and the member list right on the team header — alongside the Import Roster action.

Onboarding, step 3 of 4

A coach who creates a team at sign-up lands in a short setup wizard — team profile, roster import, then Invite your team, the same code and member list, with a Share action built in.

Bringing in the roster itself is a separate step.

The join code gets people into the team account. The roster — names, ages, genders — comes in as a CSV, validated row by row.
