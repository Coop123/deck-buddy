What the deadline actually locks

Past Meet.entryDeadline, the editing surface for new entries disappears. Scratches, relay swaps, the SDIF export, and simulation all keep working — only adding a fresh entry stops.

Seed times, everywhere

Every entry row shows its seed time inline — the same number the relay builder reads when it ranks candidates for an open leg, and the same one the simulation engine starts from.
