Deck software

Nine pillars,everything that's in each one.

No roadmap items, no "coming soon." Open a box for a preview, or click it to see that pillar walked through step by step — the same nine pillars from how it works.

View Meet sheet feature

Meet sheet

Searchable, filterable to your own swimmers, with a Now marker sitting over the current event.

  • Now marker
  • Program view
  • Derived event status — UPCOMING → NOW → FINAL
  • Search + team filters
  • Heat pointer
  • DQ badges
  • Entries / seed display
View Live console feature

Live console

Last final, current event as LIVE — UNOFFICIAL, and what's next. Always shows something.

  • Three-tier board — last final, current, up next
  • Lane times counting up live
  • Fastest-lane marker
  • B / BR suffixes — beat seed / broke record
  • Manual heat pointer or timeline estimates
  • Relay splits panel — 4 legs, per-leg times
View DQ slips feature

DQ slips

USA Swimming or VCSL code sheets, compact multi-code badges like DQ 1C,3D.

  • USA Swimming 7-category sheet
  • VCSL coded sheet
  • Custom JSON / CSV import, row-validated
  • Multi-code toggle modal
  • Compact DQ 1C,3D badge + full labels
  • Same badge on sheet, console, and profile
View Guided notes feature

Guided notes

Three taps — stroke, part of the stroke, the nitpick — plus a good / needs-work verdict.

  • Ten real parts — starts, finishes, streamline, underwaters, kick…
  • Multi-select nitpicks across parts
  • Good / needs-work verdict
  • Optional write-in
  • Saves as one note per swim
View Simulation feature

Simulation

2,000 seeded Monte Carlo runs per swimmer, reusing the meet's own placing and points logic.

  • 2,000-run seeded Monte Carlo
  • Six named factors — PBs, seeds, this meet's drops, age, event load, DQ history
  • Deterministic under a seed
  • ESTIMATE label + run count shown
  • "low data" skip when history is thin
  • Coach standings — P(win meet), swing events, podium
View Roster & improvement feature

Roster & improvement

Best-time drops and a p10 / p50 / p90 band for every swimmer, not just their best.

  • Row-validated CSV import — first, last, age, gender
  • Atomic apply — one bad row never blocks the rest
  • p10 / p50 / p90 improvement band
  • "low data" flag
  • Sort by name or Meet Δ
  • Scratches shown as strikethrough + SCR text, never color alone
View Entries & scratches feature

Entries & scratches

Swimmers get a seed time and a lane; the relay builder assembles legs from the roster.

  • Seed time + lane per entry
  • Per-event or whole-meet scratches
  • Relay builder — assembles legs from the roster
  • Relay replacement when a leg scratches
  • Relay splits capture — 4 legs, current leg highlighted
  • Comparative relay builder — fastest theoretical relay per team
  • Entry deadline lock — open / editable / locked
View Meet setup feature

Meet setup

A four-step wizard — basics, sessions, events, rules — plus program import and coach assignment.

  • 4-step wizard — basics → sessions → events → rules
  • Points-table editor + relay 2× toggle
  • DQ sheet picker / import
  • Timing mode toggle — manual vs. system
  • Entry open / close window
  • Hy-Tek program import — paste or PDF
  • Results-sheet merge, matched by event # + name
View Team stats feature

Team stats

Improvement vs seeds, entries completed, and DQ rate — the numbers behind the dashboard.

  • Team standings under the meet's scoring mode
  • High points + most-improved-by-age
  • Swimmer × stroke-category report card export
  • Three scoring modes — dual, champs, table16
  • Improvement vs seeds / entries completed / DQ rate
  • Per-team colors with a WCAG contrast guard
