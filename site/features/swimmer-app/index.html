Meet sheet
Showing in preview

The same sheet, read-only

A swimmer or parent sees the exact meet sheet a coach does — the same shared component, search and all — just without the Scratches / Add Note console. Current and previous meets, no editing surface.

Projections

Their own events, and a rival

My meet simulation projects a swimmer's own entries — expected time, P(beat PB), P(top 3) — off the same seeded engine the coach side uses. Compare vs. a rival picks one swimmer from the meet and shows a P(you win) per shared event, framed neutrally — never a taunt.

Messages

Real threads with a coach

Server-backed conversation threads: last message and unread count in the list, an inverted bubble view with optimistic send in the conversation itself.

Notifications

DQs, notes, and messages

One feed for everything that lands on a swimmer — a DQ from the meet, a coach's note, a new message — each summarized by kind. Opening the screen is the read receipt.

Profile

Claim it, then customize it

Link the account to a name on the team roster, then add a short bio and a SwimCloud id. A parent instead follows one or more swimmers and gets a block per swimmer.
