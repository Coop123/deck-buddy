Their own view,same sheet.

A swimmer or parent isn't looking at a simplified copy — it's the exact same MeetSheetView component the coach runs, rendered read-only.

What's identical

Search, team filtering, the Now marker, DQ badges, record chips — everything a coach sees on the sheet itself renders exactly the same way for a swimmer or parent.

What's gated off

No Scratches / Add Note console — there's no coach console on this side at all. Tapping a swimmer's name still opens their profile peek, just without edit actions.

Read-only, not read-down
