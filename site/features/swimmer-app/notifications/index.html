Swimmer & parent appSwimmer & parent app · Notifications

One feed,honestly scoped.

Every DQ, coach note, and message lands in one real, server-backed feed — summarized by kind, with opening the screen as the read receipt.

What's real

The server fans out a real notification on a DQ or a new message, plus coach notes; the client caches and polls for them every 60 seconds.

What isn't built

Push notifications — an alert while the app is closed — are genuinely absent: no device permission request, no token handling. This feed only updates while the app is open.

In-app, not push — yet
